# Карта доставки (PWA)

Одно приложение, три роли по логину и паролю: администратор, агент, доставщик.
Данные — Supabase (таблицы `dl_*`, доступ только через RPC, схема в `supabase/schema.sql`).
Карта — Leaflet + OpenStreetMap, маршруты — OSRM (запасной расчёт по прямой).

Версия: `version.json`, `js/app.js` (VERSION), `sw.js` (имя кэша) — повышать везде при релизе.
